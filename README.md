## Adicionar à tela inicial do celular

Envie também `manifest.webmanifest` e os ícones `assets/icon-180.png`, `assets/icon-192.png` e `assets/icon-512.png` para o repositório, junto com o `index.html` atualizado.

- Android (Chrome): abra https://ingridslv.github.io/vdgm/ e use o menu ⋮ → Adicionar à tela inicial → Instalar (o nome pode variar).
- iPhone (Safari): abra o endereço, toque em Compartilhar → Adicionar à Tela de Início. Ative “Abrir como App” se essa opção aparecer e confirme em Adicionar.

Abra pelo novo ícone para usar o modo aplicativo, sem a barra de endereço nos navegadores compatíveis. A instalação depende da confirmação do usuário no celular. Esta configuração não adiciona funcionamento offline. Os caminhos relativos também funcionam na subpasta `/vdgm/` do GitHub Pages.
